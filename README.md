# TypeZone

A clean, interactive, and responsive web app to test and improve typing speed and accuracy in real-time.

## Features
- Real-time WPM (Words Per Minute) tracking
- Accuracy measurement with detailed statistics
- Random text generator for varied typing practice
- Responsive design for desktop and mobile devices
- Interactive user interface with instant feedback
- Performance analytics and progress tracking

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/sahibaGalaxy02/typezone.git
   cd typezone
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

The app will open in your default browser at `http://localhost:3000`

## Usage

1. Click "Start Test" to begin a typing test
2. Type the displayed text as accurately and quickly as possible
3. Your WPM and accuracy will update in real-time
4. Complete the test to see your final statistics

## Technologies Used
- React.js
- HTML5
- CSS3
- JavaScript

## Performance Metrics

TypeZone tracks:
- **WPM**: Words typed per minute
- **Accuracy**: Percentage of correctly typed characters
- **Time**: Duration of typing test
- **Errors**: Total number of typing mistakes
