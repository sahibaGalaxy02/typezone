# TypeZone

A clean, interactive, and responsive web app to test and improve typing speed and accuracy in real-time.

## 🌐 Live Demo
[https://typezone.vercel.app/](https://typezone.vercel.app/)

## ✨ Features
- Real-time WPM (Words Per Minute) tracking
- Accuracy measurement with detailed statistics
- Random text generator for varied typing practice
- Responsive design for desktop and mobile devices
- Interactive user interface with instant feedback
- Performance analytics and progress tracking

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sahibaGalaxy02/typezone.git
   cd typezone
   ```

2. **Open the application:**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js http-server
     npx http-server
     ```

3. **Start typing:**
   - Click "Start Test" to begin a typing test
   - Type the displayed text as accurately and quickly as possible
   - Your WPM and accuracy will update in real-time
   - Complete the test to see your final statistics

## 📊 Performance Metrics

TypeZone tracks:
- **WPM**: Words typed per minute
- **Accuracy**: Percentage of correctly typed characters
- **Time**: Duration of typing test
- **Errors**: Total number of typing mistakes

## 🎯 How It Works

The application:
1. Generates random text for typing practice
2. Monitors user input character by character
3. Calculates real-time metrics (WPM, accuracy, errors)
4. Provides instant visual feedback
5. Displays comprehensive statistics upon test completion
